# QuickTask — Mini Task Manager

A responsive task manager built using **HTML, CSS and vanilla JavaScript**. It is a small beginner-friendly portfolio project that demonstrates DOM manipulation, event handling, filtering and browser storage.

## Features
- Add and delete tasks
- Mark tasks as completed
- Filter all, active and completed tasks
- Clear all completed tasks
- Save tasks in `localStorage` so they remain after refreshing
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No dependencies, build tools or server are required.
